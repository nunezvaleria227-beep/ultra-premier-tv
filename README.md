# Red Max Plus — app para Fire TV y Android

Reproductor de TV en vivo, películas y series para Fire TV, Fire TV Stick y celulares Android.
Entra con usuario y contraseña; el servidor ya viene configurado (`app/src/main/java/com/example/mitvplayer/Config.kt`).

Cada cambio compila el APK en GitHub Actions (`.github/workflows/redmax-apk.yml`) y lo publica.

Hecha a partir del código de Ultra Premier TV, con nombre, logo y diseño propios (negro y rojo).
